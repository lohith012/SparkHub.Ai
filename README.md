# ⚡ SPARK-HUB.Ai — Discover the Best AI Tools for Every Need

SPARK-HUB.Ai is a modern, responsive web application designed to help users discover, search, filter, bookmark, and explore curated artificial intelligence tools across diverse categories.

---

## ✨ Features

- **🎯 Curated AI Tools Directory**: Explore top AI tools across 10+ categories (Development, Design, Productivity, Writing, Marketing, Video, Audio, Education, 3D, and more).
- **🌗 Custom Theme Selector**: Switch smoothly between **OS Default**, **Light Mode**, and **Emerald Night & Mint Glow Dark Mode**.
- **🔍 Instant Search & Keyboard Shortcut**: Quick search modal powered by `Ctrl + K` (or `Cmd + K`) with real-time filtering and category badges.
- **❤️ Favorites & Saved Collections**: Bookmark and favorite tools with local persistence for instant access.
- **⚡ Tech Stack Compliance**: Built strictly using **HTML5, Vanilla CSS, JavaScript (ES6+), and React.js**.
- **📱 Fully Responsive**: Fluid navigation, mobile drawer menu, and glassmorphism styling across all viewports.

---

## 🚀 Tech Stack

- **Frontend**: React.js 19, JSX
- **Styling**: Vanilla CSS, Modern Design System with Tailwind utility tokens & CSS custom properties
- **Icons**: Lucide React & Custom SVG Vector Icons
- **Routing**: React Router DOM
- **Bundler & Dev Server**: Vite

---

## 🛠️ Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/lohith012/SparkHub.Ai.git
cd SparkHub.Ai
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for Production
```bash
npm run build
```
